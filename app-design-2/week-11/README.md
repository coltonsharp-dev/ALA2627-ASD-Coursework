# The Blue Plate — Week 11

Unit 04 of App Design 2 is a restaurant. The kitchen is a Flask server you run; the floor is a
page you write in the game; the pass tests both against one contract.

Play: https://thebrightworkhouse.com/blueplate/ — clock in with your badge phrase from Canvas.

- `kitchen/` — the Line. `pip install -r requirements.txt`, `python app.py`, set port 5000 to
  Public in the Ports panel, paste the forwarded address into the game. Tickets 1 to 5.
- `floor/` — the Floor. The same files the game starts you with, for working at home. Your real
  work is in the game, where it saves to the restaurant.

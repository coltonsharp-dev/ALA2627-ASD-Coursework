Refactor your CSS into sections

Friday, 11 September 2026

Today's objective

Reorganise my own stylesheet so someone else could find things in it.

Course learning outcome

I can turn a plain HTML page into something that looks designed — colour, type, spacing and layout.

You have met today's objective when

  • I can group my rules by the part of the page they style
  • I can write a comment header that says what a group is for
  • I can find a colour I used more than once and give it a name
  • I can spot two rules doing the same job and delete one
  • I can open my file a week later and still know where things are

Read this first

You have written a week of CSS. It works. It is also, if you are honest, in the order you happened to think of things.

Today you do not add anything. You reorganise what is already there, which is a real job with a real name — refactoring. The code does exactly the same thing when you are done. The difference is that you can find things in it.

Three operations, in this order, and the order matters: group and label first, because you cannot see duplicates until related rules are next to each other. Then pull the repeated colours out. Then delete what is now obviously repeated.

This is a short period and you are not expected to finish. Monday's first block is for finishing. Do the operations properly rather than rushing all three.

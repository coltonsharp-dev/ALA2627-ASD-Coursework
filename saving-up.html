The colon isn't decoration — it's Python's way of saying "the rules for what happens next start here." >= means "at least as big as": saved equal to goal counts as true too, not just saved bigger.

The four spaces before print aren't for looks — they're what tells Python this line belongs to the if above it. Every line indented the same amount underneath the colon is "inside" that if; the first line back at the left edge is "outside" it again.

Day 3 · More than two answers

elif ("else if") adds another question, but it only gets checked when everything above it worked out False. You can chain as many elif lines as you need between an if and an else — Python checks them top to bottom and stops at the first one that's True. / divides, so goal / 2 is exactly half of goal.

score = 75
if score >= 90:
    print("A")
elif score >= 70:
    print("B")
else:
    print("C")
OutputB

Watch out Order matters. Python stops at the first True line it finds and skips the rest — put a wide condition too early and it can catch cases a later, more specific line was supposed to handle.

Day 4 · Doing it again until it is done

while works like if, but it doesn't check its question just once. After the indented lines under it finish running, Python goes right back up to the while line and checks the condition again — and again — running that block over and over for as long as the answer stays True.

count = 0
while count < 3:
    print(count)
    count = count + 1
Output0 1 2

Watch out saved < goal has to become False eventually, or this runs forever. That only happens if something inside the loop changes saved — which is exactly what the next line does. Skip that line and you've built an infinite loop that never lets the page respond again.

Day 4 · Doing it again until it is done

A while loop does not count passes by itself — it rechecks its condition every single time, top to bottom, and stops the instant that condition comes back False. If nothing inside the loop changes the value the condition depends on, it never stops on its own. That's what an infinite loop actually is: not a loop that runs forever on purpose, but one where nothing ever made the condition False.

Day 5 · Going through a list

A for loop already knows how many times to run — once for every item in the list — so there's no condition to write and no counter to update by hand, unlike while. Each time through, item holds the next value from spent: first 12, then 8, then 25.

colors = ["red", "green"]
for c in colors:
    print(c)
Outputred green

Watch out item is a name you're choosing, not a fixed keyword — it could be called anything. Whatever you call it here has to match exactly what you type inside the loop body on the next two lines, or Python won't know what you mean.
